# TE3 UI live evidence, 2026-10-21–22

This is a dated observation record, not the current locator map. See [UI-MAP](../UI-MAP.md) for current guidance.

> **Historical record; superseded snapshot behavior.** The dated rows below describe a former three-file snapshot that included `Preferences.json`. Current `te3_layout snapshot` and `restore` handle only `Layouts.json` and `UiPreferences.json`; `Preferences.json` can contain connection and provider credentials. Treat old three-file snapshots as private: the current tool cannot restore them. See [current layout guidance](../README.md#te3-mcp-tools) and [the current file list](../../src/FlaUI.Mcp.Te3/LayoutFiles.cs).
